# Tactical Ops

[Играть в браузере](https://abv3000.github.io/tactical-ops/)

Браузерный 3D-шутер на основе [claude-of-duty-optimized](https://github.com/kamilch1k/claude-of-duty-optimized).

- Карты, модели оружия, рук и солдат, текстуры и звуковые буферы подготовлены заранее.
- Сенсорное управление: левый джойстик, обзор свайпом справа, стрельба, прицел, бег, прыжок, перезарядка, смена оружия и пауза.
- Быстрый режим включён по умолчанию. На компьютере исходное освещение и более крупные текстуры доступны в меню «Графика → Детальная». На телефоне по умолчанию выбрана тренировочная карта.
- До начала матча скачиваются только материалы выбранной карты, оружия и персонажей. Готовые звуки загружаются после первого кадра. Отражения в быстром режиме подготовлены офлайн.

## Запуск из GitHub

Нужен Node.js 22+.

```sh
npm ci
npm run dev
```

Готовые ресурсы входят в репозиторий и находятся в `public/baked/`. При сборке проверяется наличие файлов; в браузере они загружаются по мере подготовки матча.

```sh
npm run build
npm start
```

Готовая версия работает через локальный HTTP-сервер; открытие HTML через file:// больше не поддерживается.

## Подготовка ассетов

Обычная сборка проверяет готовые файлы и не генерирует их заново. При изменении генераторов выполните соответствующую команду:

```sh
npm run bake:worlds
npm run bake:models
npm run bake:environment
npm run bake:nav
npm run bake:textures
npm run bake:loadouts
# Для звуков запустите Vite в другом терминале:
npm run dev
# Затем:
npm run bake:audio
npm run verify:models
npm run build
```

Текстуры, отражения для быстрого режима и аудио запекаются офлайн через Playwright и установленный Chrome. На macOS Chrome обнаруживается автоматически; на других платформах задайте `CHROME_PATH`. Опциональный Sharp даёт lossless WebP; без него сборщик сохраняет PNG. Для аудио при другом адресе сервера задайте `BAKE_URL`. После изменения карт или материалов пересоберите списки загрузки командой `npm run bake:loadouts`.

Шейдеры WebGL компилирует драйвер устройства игрока. Их нельзя переносимо запечь как текстуры и геометрию. Пространственные фильтры звука, анимация, физика и частицы работают во время игры.

## Управление

Компьютер: WASD — движение, мышь — обзор, ЛКМ — огонь, ПКМ — прицел, R — перезарядка, Shift — бег, Space — прыжок, Ctrl — присесть, Esc — пауза.
Телефон: экранные кнопки и джойстик. Рекомендуется горизонтальная ориентация. Для работы нужен современный браузер с WebGL2.
